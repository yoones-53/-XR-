# 18Building 기획용 공간 모델

## 게임플레이 워크플로우 버전

- `18Building_Gameplay_Workflow.blend`: 기존 공간 모델에 선택 경로와 편집 가능한 흐름도를 추가한 블렌더 원본.
- `18Building_Gameplay_Workflow.png`: 기획서 삽입용 3300×1980 이미지.
- 파란 경로는 이상현상이 없다고 판단하고 엘리베이터를 선택하는 경로입니다.
- 주황 경로는 이상현상이 있다고 판단하고 시작지점 뒤 계단으로 돌아가는 경로입니다.
- 정답 선택 시 1층인지 확인하고, 1층이 아니면 n-1층으로 이동한 뒤 이상현상을 다시 결정합니다. 오답이면 5층으로 복귀합니다.
- 최초 5층이 정상 튜토리얼이라는 표시는 `AnomalyManager.cs`에 근거했습니다.
- 엔딩 프로세스는 사용자가 제공한 기획 흐름을 표현했습니다. 현재 `GameManager.cs`의 1층 정답 처리 자체는 클리어 로그 출력 후 5층 초기화로 되어 있습니다. 이 작업은 Unity 게임 로직을 변경하지 않습니다.

이전 블렌더 원본과 이미지는 보존했습니다.

- `18Building_Concept.blend`: 편집 가능한 블렌더 원본.
- `18Building_Overview.png`: 기획서용 조감도.
- `18Building_TopView.png`: 공간 배치를 설명하는 평면도.

## 반영한 내용

`Assets/Scenes/18Building.unity`가 참조하는 `Assets/18Map/Prefabs/Ceils/Corridor.prefab`과 하위 프리팹을 읽어 바닥 모듈, 복도 폭과 길이, 분기 복도, 문 위치, 엘리베이터 구역, 포스터 위치를 반영했습니다. 씬의 Corridor 프리팹에 지정된 위치·회전·스케일 변경값도 읽었습니다. Unity 원본 파일은 수정하지 않았습니다.

## 기획서 가독성을 위한 표현

- 천장은 생략하고 벽은 낮게 표현했습니다.
- 흰색은 복도와 벽, 황토색은 문, 파란색은 창, 청록색은 엘리베이터와 이동 공간 표시입니다.
- 계단은 원본의 여러 층에 걸친 계단 대신 같은 구역에 간단한 왕복 계단 형태로 표현했습니다.
- 창은 원본 창 모듈의 반복 위치를 기준으로 단순화했습니다.
- 실내 소품, 게임 캐릭터, 조명 기구, 충돌체, 이벤트 트리거, 텍스처와 이상현상 연출은 생략했습니다.
- 청록색 선과 01~04 번호는 공간 설명용으로 추가한 표시이며, 게임의 확정된 진행 경로를 의미하지 않습니다.
- 문 너머 실내 공간은 원본에서 확인되지 않아 추가하지 않았습니다. 실시 설계도나 정밀 복제 모델이 아닌 공간 설명용입니다.

## 컬렉션

01 건축 / 02 문과 창 / 03 단순화 계단 / 04 번호와 안내선 / 05 카메라와 프레젠테이션.

`90_Unity_Primitives_Reference_HIDDEN`에는 추출한 기본 도형을 참고용으로 보관했으며 기본적으로 숨겨져 있습니다. FBX 메시와 일부 중첩 프리팹의 연결은 이 참고 컬렉션에서 완전 재현하지 않습니다.

`inspect_unity.py`, `unity_geometry.json`, `build_concept.py`는 추출 근거와 재생성용 자료입니다.
